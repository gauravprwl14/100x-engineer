Fishbone / 5 whys

What it is: A root-cause diagram shaped like a fish skeleton: the problem is the head, and each bone is a category of possible causes.

What it does for the reader

  • Organises many possible causes so none are forgotten.
  • Separates symptoms from root causes.
Best forRoot causes
Avoid whenOnly one cause — just say it
FormatsHTML/SVG · React · Mermaid

Example: Possible causes of slow redirects at peak.

How to read it
  • The box on the right is the problem.
  • Each bone is a cause category (e.g. cache, database); the small text is a specific cause.
Notes on this example
  • Spine points to the effect; each bone is a cause category.
  • Illustrative causes for slow redirects.

How to build it: SVG spine with angled bones. Markdown: a table (category · cause) or a 5-whys chain in Mermaid flowchart TD.
