Bar comparison

What it is: Horizontal bars whose length shows the size of each value.

What it does for the reader

  • Makes differences in magnitude obvious at a glance.
  • Shows which value dominates.
Best forComparing magnitudes
Avoid whenPrecise values matter more than shape — use a table
FormatsHTML/SVG · React · Mermaid

Example: Writes vs reads vs peak reads per second — reads dominate, which is why caching matters.

How to read it
  • Longer bar = bigger value.
  • Here the scale is logarithmic: each step is 10×, because the values differ hugely.
Notes on this example
  • Log scale: each gridline is 10×.
  • Shows reads dwarf writes — the reason caching matters.

How to build it: SVG rectangles sized by value (log scale when values span orders of magnitude). Markdown: a table.
