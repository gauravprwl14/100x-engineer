Highlighted anatomy

What it is: One real artefact (a URL, prompt, config line) with each part coloured and a legend explaining the colours.

What it does for the reader

  • Shows the structure hidden inside something that looks like one string.
  • Teaches the name of each part.
Best forShowing the parts of one artefact (URL, prompt, config)
Avoid whenThe artefact has no meaningful parts
FormatsHTML · Markdown (bold/code)

Example: The parts of a short URL: domain, short code, optional tracking.

scheme + domain short code optional tracking

https://sho.rt/ aB3xK9q ?utm_source=mail
How to read it
  • Match each coloured part to the legend above it.
Notes on this example
  • Colours map to the legend above the box.
  • Illustrative URL.

How to build it: Coloured spans with a legend. Markdown: bold/code for each part with a list explaining them.
