Mind map (radial)

What it is: One central idea with its sub-topics radiating outward like spokes.

What it does for the reader

  • Shows that the sub-topics are peers — no order, no hierarchy.
  • Good for a quick 'what are all the parts?' overview.
Best forOne topic with many branches of equal weight
Avoid whenBranches with an order — use flow
FormatsHTML/SVG · React · Mermaid

Example: The six aspects of a URL shortener: keys, redirects, storage, cache, analytics, capacity.

How to read it
  • Start at the centre; each spoke is one independent aspect.
  • Colour groups related spokes.
Notes on this example
  • Centre = topic; colour = category (blue sizing, teal design, green ops, violet data).
  • No order implied — radial layout says 'these are peers'.

How to build it: SVG: centre ellipse, nodes placed around a circle. Markdown: Mermaid mindmap.
